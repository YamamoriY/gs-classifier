# ノイズ除去

## 概要

3DGSデータからノイズを除去する処理です。

## 手法

### 2次元DBSCAN (`denoise_2d_dbscan`)

2次元平面上でDBSCANクラスタリングを行い、最大のクラスタを抽出します。

- **パラメータ**: `radius` (デフォルト: 0.1)
- **手法**: DBSCANでクラスタリングし、点数の多いクラスタを残す
- **用途**: 初期のノイズ除去

### 3次元密度フィルタ (`denoise_3d_density`)

密度の低い点を除去します。

- **パラメータ**: 
  - `radius` (デフォルト: 0.1): 検索半径
  - `point_count` (デフォルト: 200): 最小点数
- **手法**: 各点の周辺（円柱状）の点数をカウントし、閾値未満の点を除去
- **用途**: 幹抽出前の精密なノイズ除去
