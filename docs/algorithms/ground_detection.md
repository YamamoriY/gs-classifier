# 地面検出

## 概要

3DGS データから地面を検出し、地面・地面下・地面上に分類します。

## 手法

### 四分木による地面高さ推定

四分木を使用して、フィールド全体の地面の高さを推定します。

1. **四分木の構築**: フィールドを再帰的に 4 分割し、各セルで地面の高さを推定
2. **高さ推定**: 各セル内で、円柱状の範囲内の点の高さ分布から最頻値を取得
3. **補間**: 四分木の結果から線形補間関数を作成

### 分類

補間された地面の高さから、各点を以下の 3 つに分類：

- **地面下** (`under_threshold` より低い)
- **地面** (`under_threshold` から `above_threshold` の間)
- **地面上** (`above_threshold` より高い)

**パラメータ**:

- `under_threshold` (デフォルト: 0.1): 地面下判定の閾値
- `above_threshold` (デフォルト: 0.2): 地面上判定の閾値
- `depth` (デフォルト: 6): 四分木の深さ
