# 幹分類

## 概要

地面上のデータから幹を検出・分類します。
このクラスは地上高 1-2m 程度の切り出された範囲を受け取ることを想定しています。

## 処理の流れ

### 1. DBSCANクラスタリング (`dbscan_trunk`)

2次元平面上でDBSCANクラスタリングを行い、幹の候補を抽出します。 \
より正確には、高さz方向の距離の重みを小さくして圧縮した状態で処理をします。

### 2. 高さ範囲チェック (`is_trunk_check_range`)

高さ方向の範囲が狭いクラスタをノイズとして除去します。 \
地上 1-2m を切り出した場合、幹は必ず下から上まで詰まっているからです。最後までチョコたっぷりです。

### 3. Z軸DBSCAN (`is_trunk_dbscan`)

Z軸のみでDBSCANを行い、クラスタ数が1つでないものをノイズとします。 \
これはz軸的に途中が中空である場合は、幹でない、と判断することを意味します。

理論的には 2, 3 を組み合わせれば、「高さ 1-2m あたりに縦長でずっと分布しているノイズ」以外は取り除けることになります。

## その他の手法（未使用）

- `is_trunk_fit_line`: 直線フィットによる検証
- `is_trunk_std`: 標準偏差による検証
